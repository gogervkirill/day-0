# Алматы: Сбой — прототип

**Играть:** https://gogervkirill.github.io/day-0/ (на телефоне: «Добавить на главный экран», разрешить геолокацию)

Офлайн-выживание на карте Алматы: сетка из квадратов 250 м, туман войны, лут, ловушки,
враги в реальном времени, захват клеток и районов. Есть режим GPS.

## Файлы
- `index.html` — вся игра (без сборки и зависимостей)
- `sw.js` — офлайн-кэш: оболочка игры и просмотренные тайлы карты
- `manifest.webmanifest`, `icon.svg` — установка на телефон как приложение (PWA)

## Запуск на GitHub Pages (нужен HTTPS для GPS и офлайна)
1. Создай репозиторий, загрузи в корень все файлы из архива.
2. Settings → Pages → Source: Deploy from branch → `main` / root.
3. Открой `https://<user>.github.io/<repo>/` на телефоне → «Добавить на главный экран».
4. Разреши геолокацию и нажми 📡, чтобы включить GPS.

Локально: `python3 -m http.server 8080` → http://localhost:8080. GPS работает и на localhost.

## Карта
- Подложка: стандартные тайлы OpenStreetMap (© OpenStreetMap contributors), затемнены фильтром canvas. Сервер OSM допускает только лёгкую нагрузку, поэтому для релиза и мультиплеера нужен свой PMTiles или тайл-сервер.
- Без сети игра рисует упрощённую схему: главные улицы, реки, граница города.
- По умолчанию границы районов и объекты заданы приблизительно. Точные данные даёт скрипт ниже.

## Точные данные OSM (границы районов, аптеки, магазины, больницы, АЗС…)
1. Нужен Python 3.8+ (Windows: python.org, при установке отметь «Add to PATH»).
2. В папке игры выполни: `python tools/fetch_osm.py` (на Windows: `py tools\fetch_osm.py`).
   Скрипт сделает 4 запроса к Overpass API (1–5 минут) и создаст `osm_almaty.js` в корне игры (обычно 0,5–2 МБ).
3. Загрузи `osm_almaty.js` на GitHub рядом с `index.html`. Игра подхватит его сама:
   - реальные границы города и 8 районов;
   - клетка с реальным магазином, аптекой, больницей, АЗС или гаражами получает этот тип и название («Аптека «Европа» +2»);
   - пустые клетки становятся жилыми кварталами, офисами или пустырями;
   - без тайлов рисуются реальные главные дороги и реки.
Если файла нет, игра работает на встроенных приблизительных данных. Сохранения совместимы, но при переходе на точные данные
районы клеток могут смениться, и прогресс захвата районов пересчитается.

## Где менять баланс (в index.html)
`MOVE_R`, `SEC_PER_CELL`, `EN_PER_CELL`, `RESPAWN`, `RATE`, а также таблицы `ITEMS`, `LOOT`, `ENEMY` и `POIS`.

Сохранение хранится в localStorage браузера (ключ `almaty-sboy-v1`).
